## 记录

### 2026-11-16（骨架）

**完成**

- 后端骨架：FastAPI，健康检查接口 `/api/health` 逐项报告数据库、缓存、模型服务的连通情况。
- 前端骨架：Vue 3 + TypeScript，占位页显示健康检查结果。
- `docker-compose.yml`：db、redis、backend、web 四个服务，只对外暴露 web 端口（默认 8080）。
- README 写明服务器部署步骤、成功判定和常见失败处理。

**验证情况**

- 已验证：前端生产构建通过；后端本地启动，健康检查在依赖不可用时正确报告异常且能识别密钥文件；打包命令产出的文件清单正确。
- 未验证：本机没有 Docker，镜像构建和 `docker compose up` 没有实际跑过；模型服务在内网，本地连不上，真实连通性要等服务器上验证。

**决策**

| 决策 | 结论 | 原因 |
|---|---|---|
| 模型密钥 | 以只读文件挂进后端容器，不进镜像、环境变量和代码 | 密钥在服务器固定路径，避免外泄 |
| 模型名 | 配置项留空时自动取模型服务返回的第一个 | 模型名尚未提供 |
| 依赖版本 | 后端锁定具体版本，前端用 lock 文件 | 本地与服务器构建结果一致 |

**下一步**

推送到 GitHub，由执行方拉取、启动并回报 `/api/health` 的返回内容。
