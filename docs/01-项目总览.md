# 项目总览

更新日期：2026-11-16

## 一句话说明

供内部团队使用的 A 股对话式投研网页应用：用户用自然语言提问，自研模型调用行情、财报、新闻数据后作答，回答可带 K 线、图表、表格和原文链接。

## 范围

**首版包含**

- 五类问题：个股分析、财报解读、行情查询、条件选股、政策与新闻解读
- 注册登录、多用户数据隔离
- 历史会话：保存、搜索、重命名、删除、导出 PDF
- 最多 300 人同时在线，模型并发 200，超出排队

**首版不包含**

手机适配、App、小程序、站内分享链接、注册限制、管理后台、账号停用、用量查看。

## 已定的前提

| 项 | 结论 |
|---|---|
| 模型 | 自研，以 API 提供，支持流式输出和工具调用，约 200 token/秒，并发上限 200 |
| 数据源 | AkShare（行情、财报、新闻） |
| 使用者 | 内部团队，任何拿到网址的人可自行注册 |
| 终端 | 仅桌面网页 |

## 验收标准

每条按"触发条件 → 预期行为 → 检查方式"书写，全部通过即首版验收通过。

### 账号与隔离

| 编号 | 触发条件 | 预期行为 | 检查方式 |
|---|---|---|---|
| A1 | 未登录打开任意页面 | 跳转到登录页 | 未登录直接访问会话地址，看不到任何会话内容 |
| A2 | 新用户提交注册信息 | 账号创建成功，无邮箱域名、邀请码或审核限制 | 用任意新账号注册后可立即登录 |
| A3 | 用户甲访问用户乙的会话地址 | 拒绝访问 | 返回无权限提示；甲的列表和搜索里看不到乙的会话 |

### 对话与数据

| 编号 | 触发条件 | 预期行为 | 检查方式 |
|---|---|---|---|
| B1 | 发送任意问题 | 1 秒内出现反馈（状态提示或正文） | 在 200 个并发请求以内计时，全部不超过 1 秒 |
| B2 | 模型开始作答 | 正文流式逐步显示 | 可见逐字输出，不是整段一次出现 |
| B3 | 交易时段问某只股票的当前行情 | 返回最新价并标注数据时间 | 数据时间距提问时刻不超过 5 秒 |
| B4 | 要求某只股票的分钟、日、周、月 K 线 | 显示对应周期的 K 线图（生成时的快照，不自动刷新） | 四类周期各抽查一次，图中数据与 AkShare 一致 |
| B5 | 要求分析某只股票 | 回答引用行情和财务数据，并附来源链接 | 抽查回答中的数字，与 AkShare 一致 |
| B6 | 要求解读某公司某期财报 | 回答包含财务图表或数据表格 | 图表和表格中的数字与 AkShare 一致 |
| B7 | 用估值、财务、行情、技术指标、行业概念任一类或组合条件选股 | 以表格返回结果 | 五类条件各测一次，抽查表中股票均满足条件 |
| B8 | 询问当天的财经新闻或政策 | 回答包含当天发布的内容，每条附原文链接 | 链接可打开，原文与回答对应，发布日期为当天 |
| B9 | 数据源取数失败 | 模型继续作答，并标明哪些数据未获取 | 人为断开数据源后提问，页面不中断，回答中有明确标注 |
| B10 | 并发请求超过 200 | 超出的请求排队等待，轮到后自动开始 | 压测 201 个以上并发，无报错，排队中的页面有等待提示 |
| B11 | 300 人同时在线 | 登录、查看历史、提问均正常 | 压测 300 个在线会话，无错误响应 |

### 历史会话

| 编号 | 触发条件 | 预期行为 | 检查方式 |
|---|---|---|---|
| C1 | 结束对话后重新登录 | 会话仍在列表中，可继续对话 | 退出再登录，打开旧会话追问，模型能接上文 |
| C2 | 在历史中搜索关键词 | 列出标题或内容含该词的会话 | 用只出现在某会话正文里的词搜索，能找到该会话 |
| C3 | 重命名会话 | 列表显示新名称 | 刷新页面后新名称仍在 |
| C4 | 删除会话 | 会话从列表和搜索中消失 | 删除后用原地址访问，提示不存在 |
| C5 | ~~导出会话为 PDF~~ | 2026-11-19 用户决定不做 | — |
| C6 | 距最后一次对话超过一个月 | 会话自动删除 | 构造超期会话，确认列表和搜索中都不存在 |

## 后续功能候选

2026-11-19 调研同类产品（同花顺问财、东方财富妙想、万得 Alice、富途牛牛、开盘啦、券商 AI 应用）后整理。"数据"一列为本项目能否取到，均已在本地或服务器验证过的来源标"已有"。

2026-11-20 用户决定先做 N1–N3（本地已完成，待服务器验证）；N4–N8 暂不做。

N1–N3 的做法（用户未逐条指定、由开发方按调研结论定的细节，可调整）：

- N1 诊股为五项而不是调研时写的四项：在基本面、技术面、资金面、消息面之外单列"估值"，因为估值高低与公司好坏是两回事，混在一起打分会互相抵消。每项 0–100 分，50 分为中性；规则由程序计算，模型只解读，不给买卖建议。
- N2 提醒只在站内（顶栏铃铛 + 右上角弹出），不发邮件或短信。涨跌幅阈值每只股票单独设置，默认 ±5%。
- N3 早报 8:45 起生成，复盘 15:30 起生成，只在交易日生成；全站共用一份，不按用户自选股定制。
